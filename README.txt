Final Project Proposal

Background:
Speech Emotion Recognition (SER) is complex due to the interaction of 
linguistic and paralinguistic qualities that can determine the sentiment of 
speech. Current research suggests that there are a variety of models and 
data processing techniques that have shown to have strengths in this task. 
However cross-speaker generalization is a challenge due to high risk for 
speaker specific bias during model development.

This project was chosen because I would like to gain experience in machine 
learning tasks with audio data.

Experimental Question:
This project evaluates the performance and generalizability of various 
speech emotion recognition models by comparing how feature extraction 
techniques, such as Kalman Filter temporal smoothing or wav2vec 2.0 acoustic 
embeddings, reduce speaker bias in cross-speaker emotion classification 
compared to traditional static spectral features, like MFCC.

Proposed Dataset: 
The dataset used for this project is the Toronto Emotional Speech Set (TESS) 
obtained from Kaggle.
